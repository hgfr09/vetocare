En te basant sur l'entité PHP et le besoin React fournis, décris-moi sous forme de structure JSON théorique :
1. Ce que le client React doit envoyer (Payload POST/PUT) avec les types attendus.
2. Ce que l'API Platform va renvoyer (Response) en tenant compte des formats standards (JSON-LD / Hydra).
Cela va me servir de modèle pour coder mes interfaces.
